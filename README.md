## About Me

I'm an MSc Computer Science student at SIES Nerul with a growing focus on Artificial Intelligence and Machine Learning.

My goal is to become an AI/ML engineer who can build, understand, and deploy intelligent systems rather than simply use AI APIs.

I'm currently focusing on:

- Machine Learning & Deep Learning
- Retrieval-Augmented Generation (RAG)
- Large Language Models (LLMs)
- Embeddings & Vector Search
- Natural Language Processing
- AI system architecture
- Game AI and intelligent NPC systems

I also enjoy building complete software systems as a way to understand how different parts of modern applications work together.

## Current Focus

### NeuralNotes

My primary AI/ML project.

NeuralNotes is a RAG-based knowledge platform exploring how documents, embeddings, retrieval systems and large language models can work together to create intelligent knowledge systems.

I'm using the project to go beyond simply calling an LLM API and learn the engineering behind modern AI applications.

**Exploring:**

`RAG` · `Embeddings` · `Vector Search` · `LLMs` · `Semantic Retrieval` · `NLP`
